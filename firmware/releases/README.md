# 固件稳定版归档

每一次"确认稳定、可以交付"的固件都在这里留一份**原样 hex**（不依赖 `Objects/`，
那边每次编译都会被覆盖，而且被 `.gitignore` 忽略）。

| 版本 | 日期 | git 提交 | 标签 | 配对上位机 | 说明 |
|---|---|---|---|---|---|
| [fw-v8.0](fw-v8.0-20261110/MANIFEST.md) | 2026-11-10 | `f808ff1` | `fw-v8.0` / 分支 `stable-v8` | `car_web` 1.6.2 | **第一版可交付**：命令锁存 + 缓起缓停 + 洗地车辅助按钮（独立功能帧 `0x7A`），诊断帧 `[30]=8` |

## 约定

- 每个版本一个目录 `fw-vX.Y-YYYYMMDD/`，里面：`scrubber.hex`、`sweeper.hex`、`MANIFEST.md`。
- `MANIFEST.md` 必须写：**hex 的 MD5** 和 **镜像 MD5**（`0x08000000` 起的 bin），
  烧完回读用镜像 MD5 比对；再加上这一版的功能清单、烧录命令、自检清单。
- 归档的 hex **不允许再改动**；新改动 → 新目录、新标签。
- 取回某个版本：`git checkout fw-v8.0 -- firmware/releases/fw-v8.0-20261110`。
