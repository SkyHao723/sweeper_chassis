关于“电流”：达妙 DM-H65 反馈的是扭矩 τ（Nm）（12 bit，量程 ±40 Nm）， 不是相电流 A。固件只写控制模式，没有读 KT 寄存器（0x01 KT_Value）， 所以本页不显示“电流”，也不做 Nm→A 换算；要电流需先在固件里读 KT 再换算。
扭矩/位置是电机原始方向（固件 DM_DIR_SIGN=-1，车前进时 ω 为负）。 ERR 0=失能、1=使能都算正常，其它码红色高亮。
